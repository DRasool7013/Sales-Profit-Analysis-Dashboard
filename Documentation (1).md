# 📄 Documentation — Sales & Profit Analysis Dashboard

## 1. Project Aim / Goal

Retail businesses generate large volumes of transactional data, but raw data on its own doesn't answer business questions. This project transforms the raw **Sample Superstore** order data into a two-page Power BI dashboard so that stakeholders can quickly answer:

1. Which product category drives the most profit?
2. How do sales trend across years and quarters?
3. Which ship mode is used most, and how does it affect profit?
4. What is the average discount given per category, and how does it impact profit?
5. Which cities/states generate the highest sales?

The dashboard is designed to be filtered live via **Ship Mode**, **Segment**, **Category**, **Month**, and **Year** slicers so any stakeholder can self-serve their own view of the data.

---

## 2. Dataset Description

**Source file:** `Sample_Superstore_raw_table.xls`

The dataset is a flat transactional export of a fictional retail superstore's orders, with one row per order line item.

**Key fields in the raw file:**

| Field | Description |
|---|---|
| Order ID / Order Date | Unique order identifier and the date it was placed |
| Ship Mode | Delivery method — Standard Class, First Class, Second Class, Same Day |
| Customer ID / Customer Name | Customer identity |
| Segment | Customer segment — Consumer, Corporate, Home Office |
| City / State / Region / Country | Customer geography |
| Product ID / Product Name | Product identity |
| Category / Sub-Category | Product classification — Furniture, Office Supplies, Technology |
| Sales | Revenue generated by the line item |
| Quantity | Units sold |
| Discount | Discount rate applied |
| Profit | Profit generated by the line item |

**High-level snapshot (from the built dashboard KPIs):**
- Total Sales: **$1.10M**
- Total Profit: **$132.52K**
- Total Customers: **793**
- Total Orders: **~5K**
- Total Products: **~2K**

## 3. Data Cleaning & Modeling Process

1. **Import**: Loaded the raw `.xls` file into Power BI via Power Query.
2. **Type correction**: Converted `Order Date` to a proper Date type, and `Sales`, `Profit`, `Discount`, `Quantity` to numeric/decimal types.
3. **Deduplication**: Checked and removed duplicate rows based on `Order ID` + `Product ID` combinations.
4. **Text cleanup**: Trimmed whitespace and standardized casing on categorical fields (`Category`, `Segment`, `Region`, `Ship Mode`).
5. **Null handling**: Verified there were no missing values in core measure fields (Sales, Profit, Quantity, Discount); rows with missing dimension keys were excluded.
6. **Dimensional modeling**: Split the single flat table into a **star schema**:
   - `Fact Sales` — the transactional grain (Order ID, Order Date, Customer ID, Product ID, Ship Mode, Sales, Quantity, Discount, Profit)
   - `Dim Product` — Category, Product ID, Product Name, Sub-Category
   - `Dim Customer` — City, Country, Customer ID, Customer Name, Region, Segment, State
   - `Dim Calender` — Date, Month, Quarter, Year, Weekday (generated as a dedicated date dimension)
7. **Relationships**: Connected each dimension table to `Fact Sales` on its key column (1-to-many, single-direction filtering).
8. **Measures (DAX)**: Built explicit measures for all KPIs (`Total Sales`, `Total Profit`, `Total Customers`, `Total Orders`, `Total Products`) plus supporting measures for Profit Margin % and month-over-month sales comparison.

## 4. Final Result

A **two-page interactive Power BI dashboard**:

### Page 1 — Overview
- KPI cards: Total Sales, Total Profit, Total Customers, Total Orders, Total Products
- Sales Performance by Region (column chart)
- Profit by Segment (pie chart)
- Current Month Sales vs. Previous Month Sales (comparison chart)
- Total Sales by Segment and Category (clustered column)
- Top 10 Products by Sales (bar chart)
- Slicers: Ship Mode, Segment, Category, Month, Year

### Page 2 — Trends & Performance
- KPI cards (same five, dynamically recalculated per filter context)
- Total Profit by Category (bar chart)
- Total Sales by State (bar chart)
- Orders & Total Profit by Region (combo chart)
- Avg. Discount and Profit Margin % by Category (combo chart)
- Sales Trend by Quarter and Year (line chart)
- Same synced slicer panel as Page 1

## 5. Outcomes

- Delivered a **single source of truth** for sales and profitability that replaces manual spreadsheet reporting.
- Enabled **cross-filtering** across five dimensions (ship mode, segment, category, month, year) so any business user can slice the data without touching Power Query or DAX.
- Reduced the time to answer "how are we doing this month vs. last month" from a manual pivot-table exercise to a single glance at the KPI card.
- Standardized how sales, profit, and margin are defined and calculated across the organization via reusable DAX measures.

## 6. Insights

Answering the five guiding questions from the planning notes:

**1. Which product category drives the most profit?**
Technology and Office Supplies contribute the largest share of total profit, while Furniture consistently shows the thinnest margins relative to its sales volume — visible on the "Total Profit by Category" chart on Page 2.

**2. How do sales trend across years and quarters?**
The "Sales Trend by Quarter and Year" line chart shows sales are not flat — certain quarters (typically Q4) spike higher, indicating seasonality that should inform inventory and staffing planning.

**3. Which ship mode is used most, and how does it affect profit?**
Standard Class is the most frequently used shipping method. Faster shipping options (Same Day, First Class) are used less often but are worth monitoring, since expedited shipping can compress margins if not priced correctly.

**4. What is the average discount given per category, and how does it impact profit?**
The "Avg. Discount and Profit Margin %" chart shows an inverse relationship in some categories — higher average discounts (notably in Office Supplies) correlate with lower profit margin %, suggesting discount policy is a lever worth revisiting for that category.

**5. Which cities/states generate the highest sales?**
California and New York are the top-performing states by total sales, per the "Total Sales by State" chart, making them priority markets for continued investment.
